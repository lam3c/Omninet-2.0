# OmniNet 1.0.0

Initial Windows x64 release of OmniNet.

## Package

- Installer: `OmniNet_Setup.exe`
- Platform: Windows x64
- Installer format: Inno Setup
- Framework: Qt 6
- Release build: C++ Release configuration

## Installation

Download `OmniNet_Setup.exe` from the GitHub Releases page and run it. The installer supports a per-user installation and does not require administrator privileges.

## Important security notice

This release is unsigned. Windows Smart App Control or an organisation-managed application-control policy may prevent the installer or application from running. Do not disable Windows security protections to install it. A signed release may be provided in a future version.
